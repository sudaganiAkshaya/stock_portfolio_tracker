⭐ TASK 2: STOCK PORTFOLIO TRACKER 📈
🚀 A simple Python-based Stock Portfolio Tracker that calculates total investment using manually defined stock prices.

🌟 PROJECT OVERVIEW
The Stock Portfolio Tracker is a beginner-friendly Python project that allows users to enter stock symbols and quantities and calculates the total investment value.

The project uses a hardcoded Python dictionary to store stock prices and demonstrates basic programming concepts such as user input, dictionaries, loops, conditional statements, arithmetic operations, and file handling.

🎯 OBJECTIVE
The main objective of this project is to build a simple stock portfolio tracker that:

⭐ Accepts stock symbols from the user
⭐ Accepts the quantity of each stock
⭐ Uses manually defined stock prices
⭐ Calculates individual investment values
⭐ Calculates the total portfolio investment
⭐ Handles unavailable stock symbols
⭐ Saves the final result into a .txt file
